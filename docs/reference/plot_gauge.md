# Plot Gauge

Plot Gauge

## Usage

``` r
plot_gauge(data = filtered_df, variable = "Temperature")
```

## Arguments

- data:

  dataframe

- variable:

  one of "Temperature" "Humidity" "Pressure" "Lux" "Proximity" "NH3"
  "Reducing" "Oxidising" "PM1" "PM2.5" "PM10"
